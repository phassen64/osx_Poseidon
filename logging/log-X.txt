    Private Key (id_ed25519):
        Kept strictly secret on your local computer.
        It signs data during authentication.
        Never share this file.

        Placed on any remote server you want to access (usually stored in ~/.ssh/authorized_keys).
        Anyone can see it without compromising your security.

    sudo DEBIAN_FRONTEND=noninteractive apt-get install --assume-yes chrome-remote-desktop
}
